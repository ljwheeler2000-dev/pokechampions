# Regulation M-B Meta Report (champteams.gg)

Source: https://champteams.gg/news/reg-m-b-week-8-meta-report
Timing: Week 8 of Regulation M-B overall; Week 2 of Season M-5 specifically (M-5 is the current season running on Reg M-B).

## Methodology
36 tournaments, 1,768 player entries analyzed over a two-week window. Meta score = tournament usage + win rate + top-cut conversion + event wins, weighted by event size. Tier list: 8 S / 27 A / 14 B / 16 C / 46 D across 111 ranked Pokémon.

## S Tier
1. Kingambit — 167.2 score, 52.4% WR
2. Charizard-Mega-Y — 158.6 score, 52.6% WR
3. Basculegion — 157.9 score, 52.0% WR
4. Staraptor-Mega — 153.5 score, 51.0% WR
5. Farigiraf — 149.6 score, 50.1% WR
6. Pelipper — 148.3 score, 51.1% WR (NEW to S)
7. Sylveon — 147.9 score, 51.3% WR (NEW to S)
8. Garchomp — 146.9 score, 49.4% WR

## Tier Movements
- Up to S: Pelipper (rain), Sylveon (Tailwind)
- Down to A: Sinistcha, Incineroar — report notes they "did not get worse; sand and balance simply took fewer trophies this window than rain and Tailwind"

## Notable A Tier
- Venusaur-Mega — 57.6% WR (highest win rate in A)
- Delphox-Mega — 53.9% WR
- Froslass-Mega — 52.9% WR
- Archaludon — 50.1% WR
- Grimmsnarl — strong showing (no % captured)

## Dominant Archetypes
**Rain (top winning archetype this window):** Pelipper's Drizzle powers Archaludon (instant Electro Shot) and the rest of the rain shell; Pelipper itself brings Tailwind + Wide Guard. Player Noktuska won 3 separate events (114/83/75 entrants) with an identical rain core: Pelipper, Archaludon, Venusaur-Mega, Grimmsnarl, Basculegion, Charizard-Mega-Y.

**Sand (most-played, though slipping in results):** Core = Excadrill + Tyranitar-Mega + Sinistcha.

**Tailwind:** Charizard-Mega-Y + Sylveon + Farigiraf converting well.

**Cross-archetype glue:** Basculegion + Kingambit forms an offensive backbone that fits multiple team styles.

## Tournament Winners
- Largest event (162 players): balanced team (Sir_Aaron) — Aerodactyl-Mega, Sneasler, Kingambit
- Multiple smaller events: rain teams (see Noktuska above)

## Strategic Outlook (per report)
Expect more rain, and more answers to it: redirection + Wide Guard to blank spread moves, and fast Tailwind to race rain teams before they set up. Sand remains most-played but is losing ground to rain/Tailwind results. Season M-5 continues on Regulation M-B; Regulation M-C isn't expected until Season M-6 (September), so M-B stays the primary team-building focus.
